Research Period: 2024.01 - 2024.08

C++ / ROS2 Isaac Sim ESP32 CUDA

주요 기여 및 연구 내용

가상 환경 속에서 원격 의료 로봇이 만지는 물체의 단단함, 표면의 거칠기 등을 마스터 디바이스를 통해 인체에 고스란히 정밀 피드백하는 햅틱 디바이스 알고리즘을 공동 연구했습니다.

  • 햅틱 양방향 제어(Bilateral Control): 딜레이와 패킷 드롭으로 인한 오작동을 차단하기 위해 원격 제어 루프를 1,000Hz 주기로 강제 유지시키는 제어 보정 기법 설계.
  • Isaac Sim 기반 AI 합성 데이터 셋 구축: 실제 액추에이터의 거동을 가상 환경상에 물리 모사하여, 실제 실험 없이도 94%의 정확도로 원격 추론할 수 있는 데이터셋 가공 프로세스 주도.
  • SAM(Segment Anything Model) 적용: 원격 조종 카메라의 로봇 암 끝단과 파지 대상을 가볍고 빠르게 타겟팅하는 이미지 실시간 세그멘테이션 및 액티브 러닝 파이프라인 연동.
"가상에서 실현한 마찰력을 물리 디바이스로 1:1 복원하여 임상 테스트 단계에서의 제어 오차를 기존 대비 18% 감소시켰습니다."
자체 연구 & 구현 프로젝트

가상 환경(Sim-to-Real) 데이터 파이프라인

Project Period: 2024.09 - 2024.12

PyTorch Omniverse Active Learning

하드웨어와 스마트 AI 데이터 수집의 연결

물리 카메라를 활용한 전통적인 딥러닝 학습 데이터 준비 방식은 막대한 레이블링 비용과 하드웨어 노후화를 동반했습니다. 이 문제를 가상 시뮬레이터(NVIDIA Isaac Sim) 연동 및 Active Learning 아키텍처로 타파했습니다.

  • Active Learning 루프 구축: 추론 정확도가 80% 미만으로 도출되는 '모호한 케이스'의 프레임만을 필터링하여 레이블링 풀에 우선 적재하는 자동 선별 알고리즘 구현.
  • Sim-to-Real 간극(Gap) 해소: 도메인 랜덤화(Domain Randomization) 기술을 활용하여 텍스처, 광원, 물리적 반발 계수를 인공적으로 변형해 시뮬레이션 데이터만으로 현실 적응 정밀도를 올렸습니다.
